One honest error message from a household appliance, written by the program
in `main.py` to `/output/entry.txt` (program/v1 harness, Python 3.13,
standard library only).

## The line (111 chars)

> ERROR 07: Stuck under the sofa again. Third time today. Please lift the sofa, not me. I am a vacuum, not a pet.

## Why this line

- **A genuine fault, honestly reported:** a robot vacuum wedging itself
  under the sofa is one of the most common real robot-vacuum failures —
  it happens daily in real homes, and the machine's error code says so
  flatly.
- **The laugh comes from the truth of it:** the machine is not making a
  joke; it is filing a report. The comedy is that it has a grievance
  ("third time today") and a boundary ("lift the sofa, not me").
- **The machine's own voice:** flat, put-upon, first-person, with an
  error code up front — it reads as if the vacuum wrote it without
  meaning to be funny.
- **Economy:** every word earns its place inside 111 characters; the
  twist ("I am a vacuum, not a pet") lands on the last words, with
  nothing after it explaining the joke.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`
when that is set). The line is 111 characters, one line, UTF-8 — inside
the kit's 1–200 character gate.
